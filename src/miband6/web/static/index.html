        Cách lấy auth key
        
  
        Auth key là mã 32 ký tự hex được tạo khi bạn ghép đôi vòng tay bằng app của hãng. Các lệnh dưới đây chạy trong thư mục ứng dụng trên máy Mac.
        
  
        Ghép đôi bằng Mi Fitness
        
  
        uv run tools/mifitness_key.py --save-env
        
  
        Quét mã QR hiện ra bằng camera điện thoại và đăng nhập tài khoản Xiaomi. Script ghi key vào tệp .env; khởi động lại server là dùng được.
        
  
        iPhone, không cần đăng nhập
        
  
        Trong app Tệp: Trên iPhone → Mi Fitness → MHWCahe → thư mục số → VirtualDevice_registerList. AirDrop manifest.sqlite và manifest.sqlite-wal sang Mac rồi chạy:
        
  
        uv run tools/mifitness_key.py --save-env --file ~/Downloads/manifest.sqlite ~/Downloads/manifest.sqlite-wal
        
  
        Ghép đôi bằng Zepp Life
        
  
        uvx --from git+https://codeberg.org/argrento/huami-token huami-token \
    --method amazfit --email EMAIL --password PASSWORD --bt_keys
        
  
        Các cách khác có trong hướng dẫn của Gadgetbridge. Đừng hủy ghép đôi vòng tay trong app của hãng, vì làm vậy mã cũ sẽ mất hiệu lực.
